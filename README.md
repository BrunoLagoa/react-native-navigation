# Navegação em React Native 🚀

## 📱 Sobre o Projeto
Este é um projeto de demonstração focado em implementar diferentes estratégias de navegação em React Native, utilizando as melhores práticas e padrões recomendados. Explore diversos tipos de navegação como Stack, Drawer e Bottom Tabs em uma aplicação moderna e bem estruturada.

## 🛠️ Tecnologias Utilizadas
- React Native v0.76.9
- Expo v52.0.46
- React Navigation v7
  - Stack Navigation
  - Drawer Navigation
  - Bottom Tabs Navigation
- React Native Reanimated v3.16.1 (para animações suaves)
- TypeScript para tipagem estática

## ✨ Funcionalidades
- 📚 Stack Navigation: Navegação em pilha para fluxos sequenciais
- 🗂️ Drawer Navigation: Menu lateral deslizante
- 📱 Bottom Tabs: Navegação por abas na parte inferior
- 🎨 Animações suaves e transições personalizadas
- 📱 Layout responsivo e adaptável
- 🔒 TypeScript para maior segurança e manutenibilidade

## 📋 Pré-requisitos
- Node.js
- npm ou yarn
- Expo CLI (`npm install -g expo-cli`)
- Ambiente de desenvolvimento React Native configurado
- Um editor de código de sua preferência (recomendamos VSCode)

## 🚀 Instalação

1. Clone o repositório:
```bash
git clone <seu-repositorio>
```

2. Instale as dependências:
```bash
cd navigation
npm install
```

3. Inicie o projeto:
```bash
npm start
```

## 📱 Executando o Projeto

Após iniciar o projeto, você tem várias opções para executá-lo:

- 📱 **iOS**: `npm run ios`
- 🤖 **Android**: `npm run android`
- 🌐 **Web**: `npm run web`
